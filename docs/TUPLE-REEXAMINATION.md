# 重新推敲「多少元」——用数学而非知识库推导灵脑的形式化元组

> **缘起**：现有七元组 𝔹=(𝕎,K,Φ,Ψ,Θ,Λ,Ξ) 的设计知识来自外部知识库（IMA）。知识库不一定是最好、最合适的——它已被降级为「外部参考索引」，而非权威。
>
> 本文**不引用任何知识库条目**，纯从数学出发，针对四个建模目标重新推导：
> **真实世界 / 真实物理规律 / 真实物理机械 / 真实人类心理**。
>
> **结论（先给）**：应为 **8 元**，且与现有七元组几乎不重叠。现有七元组是一份**软件模块清单**，不是数学元组。

---

## 1. 现有七元组为什么不成立

把七个分量按**本体论类别**分拣，问题立刻暴露：

| 分量 | 真实类别 | 判定 |
|---|---|---|
| 𝕎 世界图 | 数学对象（部分） | 仅覆盖 X / 约束 / 𝕌；**无动力学、无观测通道** |
| K 知识库 | **存储** | f、h 参数的存放处，不是决策问题的分量 |
| Φ 感知 | **过程 / 算法** | 信念更新，作用在元组上 |
| Ψ 学习 | **过程 / 算法** | 参数估计，作用在元组上 |
| Θ 推理 | **过程 / 算法** | 求解器（算 argmin），不是"算什么" |
| Λ 因果 | **某对象的性质** | 因果 = 动力学 f 的干预语义 ⟹ **Λ ⊊ f** |
| Ξ 审计 | **元要求** | 可追溯性，正交于决策问题本身 |

三个要害：

1. **数据 / 过程 / 存储 / 元要求 混杂**——这不是一个数学元组，是模块划分。
2. **有 Λ（因果）却没有 f（动力学）**——本末倒置：因果是动力学的性质，没有宿主却留着性质。
3. **真正刻画"在物理世界行动"的对象大半缺位**：无 f、无 h、无 V、无 M，U 只在体外适配器里。

---

## 2. 从四个建模目标推导

判据（**不可约性检验**）：固定其余全部分量、只变这一个，决策问题是否真的不同？若不同，则它必须独立成元。

### 2.1 对真实世界建模 ⟹ `X` `h` `b`（3 元）

真实世界不是静态图，而是**带噪声的部分可观测随机过程**。

- **`X` 本体**：状态空间。对物理世界，它不是离散节点集，而是**构型流形 Q 及其切丛 TQ**（位形+速度）——这是拉格朗日/哈密顿力学强加的。离散世界图是有损近似，不应是元组的本体。
- **`h` 观测通道**：世界只能经传感器部分可见，`y = h(x) + v`。需要显式似然 `P(y|x)`；**Fisher 信息**决定"什么可学"，**可辨识性**决定"什么根本学不到"。现元组把它塞进 Φ（一个过程），因此丢失了噪声模型与可辨识性。
- **`b` 信念**：部分可观测下，agent **只能作用于信念，不能作用于真值**。POMDP 理论：信念是观测历史的**最小充分统计量**。当不确定性不可约（奈特式）时须用**不精确概率** `[belief, plausibility]`，而不是硬凑一个分布。

> 三者不可互推：同样的世界 + 不同的传感器 ⟹ 不同的信念动力学；同样的信念 + 不同的本体 ⟹ 不同的问题。

### 2.2 对真实物理规律建模 ⟹ `f`（1 元）

`ẋ = f(x, u) + w`。但物理规律不是任意 `f`，它有**必须尊重的结构**（这些不是学出来的，是硬约束）：

- **Noether 定理**：对称 ⟺ 守恒。时间平移→能量、空间平移→动量、旋转→角动量。违反者物理上不可能。
- **热力学第二定律**：耗散 / 被动性。结构上分解为 **port-Hamiltonian**（能量守恒部分）+ **metriplectic**（熵产生部分）。
- **量纲齐次性**：Buckingham π（内核已有 `THM_BUCKINGHAM_PI` 支撑），异量纲不可相加。
- **因果（Λ）就是 f 的干预语义**（do-演算）⟹ **Λ 归入 f，不单独成元**。

### 2.3 对真实物理机械建模 ⟹ `U`（1 元）

不只是"能做什么"，而是**物理机械的硬限制**：

- **饱和** `‖u‖ ≤ u_max`、**速率限制** `‖u̇‖`（真实执行器有界）；
- **非完整约束**（车轮不能侧移）——Pfaff 约束，不可积；
- **自由度与运动学**：SE(3)、Denavit–Hartenberg、雅可比、**奇异位形**；
- **执行器滞后**：u 非瞬时生效。

> **与 f 的区别**：f 是「被控对象如何演化」，U 是「你能注入什么」。同一对象换不同执行器 = 不同机器，反之亦然。数学上前者是向量场，后者是输入纤维上的容许截面。
>
> **诚实备注**：U 是 8 元中**最弱**的一项——纯粹主义者可将它并入 `f` + `Inv`。保留理由是：机构学/旋量理论是独立数学分支，且工程上执行器限制常是主导约束。

### 2.4 对真实人类心理建模 ⟹ `V` `M`（2 元）

**`V` 价值 / 偏好**——关键：**人不是期望效用最大化者**。

- **前景理论**（Kahneman–Tversky）：参照点依赖、**损失厌恶 λ≈2.25**、概率权重函数（小概率被高估）、收益区凹 / 损失区凸。
- **双曲折扣**（β-δ），非指数折扣。
- 后果：若用期望效用替人规划，会**系统性算错**——这不是精度问题，是模型错误。故 V 必须是**一般偏好泛函**，不能预设为期望效用。

**`M` 他心**——关键：**形式上也不可约**（不只是工程上）。

- 理论心智 / 递归信念：人建模你、你建模"人建模你"（level-k / I-POMDP；人类实际递归深度约 2–3）。
- **有限理性**（Simon）：满意即止，非最优——故"他人策略"不能用最优性反推。
- **形式后果**：他人的存在使转移核变为 `T(x' | x, u, π)` —— 依赖**你的策略 π**，而不只是你的动作 u。这**破坏了 Bellman 最优性所依赖的马尔可夫/平稳结构**，问题从 MDP 变为博弈 / I-POMDP。这是形式上的改变，不是工程妥协。
- 信任与接受度本身是控制变量。

### 2.5 不可逆伤害 ⟹ `Inv`（1 元）

物理机械在真实世界行动，可造成**不可逆伤害**。因此：

- **`Inv` 安全不变量**：`Inv ⊆ X` 容许集，或屏障证书 h（CBF：`L_f h + L_g h·u ≥ −α(h)` ⟹ 前向不变）。
- **为什么不能并入 V（不只是一个很大的负代价）**：
  有限惩罚在任何**近似误差**下都给不出保证；屏障证书给的是**前向不变性**（构造性保证）。
  这是**词典序（硬约束）**与**标量（软优化）**两种**不同序结构**的差别。
  ⟹ 安全必须是约束，不能是代价。这也是灵脑把 CBF / 可达集做成独立一层的数学理由。

### 2.6 合计

```
真实世界     → X, h, b          (3)
真实物理规律 → f                (1)
真实物理机械 → U                (1)
真实人类心理 → V, M             (2)
不可逆伤害   → Inv              (1)
                        ─────────
                            8 元
```

## 3. 推导出的八元组

$$
\mathbb{B} = (\,X,\; h,\; b,\; f,\; U,\; V,\; \text{Inv},\; M\,)
$$

| # | 分量 | 数学对象 | 关键结构 | 不可约理由 |
|---|---|---|---|---|
| 1 | `X` 本体 | 构型流形 Q / 可测空间 (Ω,ℱ) | 位形+速度（TQ） | 同样的其余、不同的本体 ⟹ 不同问题 |
| 2 | `h` 观测通道 | 似然 P(y\|x)；Fisher 信息 | 可辨识性、标定 | 同样的世界、不同的传感器 ⟹ 不同信念动力学 |
| 3 | `b` 信念 | POMDP 信念 / 不精确概率 | 最小充分统计量；[belief, plausibility] | 部分可观测下只能作用于信念，不能作用于真值 |
| 4 | `f` 动力学 | 向量场 ẋ=f(x,u)+w | Noether 守恒、热力学耗散、量纲齐次、干预语义(Λ) | 演化规律本身 |
| 5 | `U` 执行 | 容许控制集 U(x) | 饱和、速率、非完整约束、SE(3)、滞后 | 同一对象换执行器 = 不同机器 |
| 6 | `V` 价值 | 偏好泛函 / 序 ≽ | **前景理论**（非期望效用）、双曲折扣 | 同样的世界、不同的欲求 ⟹ 不同行动 |
| 7 | `Inv` 安全 | 不变集 / 屏障证书 | 前向不变性；**词典序优先于 V** | 硬约束 vs 标量代价是不同序结构；保证只来自不变集 |
| 8 | `M` 他心 | 递归信念 / I-POMDP / 博弈 | 理论心智、有限理性；T(x'\|x,u,**π**) | 转移核依赖你的策略 ⟹ 破坏马尔可夫/平稳性 |

### 两条横切参数（不是元组成员）

- **时间 / 视界**：γ 或 T 是**代价泛函的参数**，已吸收进 `V`，不单列。
- **审计 / 可追溯性**（现 Ξ）：是对**求解器输出**的元要求，正交于决策问题。
  **仍应保留**（这是灵脑的核心价值），但不占元组名额。
- **计算资源 / 有限理性**（元推理）：agent 自身也是物理系统， deliberation 有机会成本（Russell & Wefald）。同属元层。

## 4. 现有实现的覆盖度审计（诚实）

| 八元 | 现有覆盖 | 说明 |
|---|---|---|
| `X` | **部分** | 𝕎 的节点 𝕍 是离散图，非构型流形/切丛 |
| `h` | **缺位** | 被折叠进 Φ（过程），无显式似然/Fisher/可辨识性 |
| `b` | **部分** | Φ 中有 Banach 信念收敛；已有 `[belief, plausibility]`，但未升格为一等分量 |
| `f` | **未升格** | 只有它的**性质** Λ；𝕎 的权重 𝕨 与 K 的转移表是离散近似，无守恒/耗散结构 |
| `U` | **元外** | 仅存在于 `attachBody` 能力契约，不在元组内 |
| `V` | **缺位** | 只有「目标节点 + 边权 𝕨」，无偏好泛函；且形状是**期望效用**，未含前景理论 |
| `Inv` | **部分** | ℂ 硬约束 + CBF/可达集已实装，但作为 𝕎 的内部字段，未作为词典序独立元 |
| `M` | **缺位** | 完全没有他心模型 |

**结论（修订于 2026-08-31）**：本文原判定 8 元中**完全缺位 4 项**（h、U、V、M）、**未升格 1 项**（f）、**部分覆盖 3 项**（X、b、Inv）。
**该缺口已于 2026-08-31 落地**——内核新增可审计对象 `BrainTuple`，把 h/U/V/M 正式建模为可运行、可审计的数学对象，并把 f 升格为显式动力学函数（详见 §8）。落地采用「数学层/工程层分离」原则，**不推翻现有七元组工程**。
反过来说，现有七元组把 5 个名额花在了**不是数学对象**的东西上（K、Φ、Ψ、Θ、Ξ）+ 1 个**宿主缺失的性质**（Λ）——这一点仍成立，故八元组作为「形态学叠加层」而非替代。

## 5. 建议：元组与模块分离（而非替换）

不需要推翻七元组——**它的七个东西都有价值**，只是它们不是同一层面的东西。建议拆成两层：

- **数学层（8 元）**：`𝔹 = (X, h, b, f, U, V, Inv, M)` —— 回答「决策问题是什么」。
- **工程层（正交）**：存储 K、信念更新（原 Φ）、参数估计（原 Ψ）、求解器（原 Θ）、审计 Ξ、接口——回答「怎么算、怎么存、怎么证明你算过」。

这样 𝕌（不可判定）的语义也更清楚：**`𝕌` 不是元组成员，而是当 `b` 无法在 `Inv` 内找到可达 `V` 改进时的诚实输出状态**。

## 6. 尚未解决 / 需复核

1. **`U` 是否应并入 `f` + `Inv`**——本文保留它，但承认这是 8 元中最弱的一项。
2. **`V` 的表示**：若服务对象是**人**，是否默认采用前景理论而非期望效用？这会改变规划目标本身，需产品决策。
3. **`M` 的递归深度**：人类实际约 2–3 层。取几层？（层数越高，状态空间指数爆炸。）
4. **`X` 的离散化代价**：现实现用离散图近似构型流形。在什么条件下这个近似会**丧失安全保证**？（可达集过近似在非线性下未必保守——相关猜想见 `CONJ_NONLINEAR_REACH`。）
5. **`f` 的表示选择**：集中式 ODE vs 结构化（port-Hamiltonian + metriplectic）。后者能免费获得守恒/耗散保证，但建模成本高。

---

## 7. 原则不变

无论元组如何调整，灵脑的数学承诺不变：

> **凡追不到一条证明链的结论，宁可标 `𝕌`（不可判定），也绝不冒充已证明。**

元组的价值不在数字是 7 还是 8，而在于：**每一个元，都必须是一个能被独立质疑、独立检验的数学对象——而不是一个模块名。**

### 8.2 诚实边界（落地后必须照讲，不夸大）
- **h/U/V 是实装的数学对象**，且 h/U 复用现有安全栈（checkHard / IRREVERSIBLE-HALT / 观测契约可区分性），不是装饰。
- **f 仍是离散/声明式近似**：连续动力学仅由具身 `cap.exec` 预测，没有 port-Hamiltonian / metriplectic 守恒-耗散结构（§6.5 未决）。
- **V 是到达价值（值迭代固定点），不是前景理论效用**：服务「机器人到达」目标足够；若面向人需前景理论，属 §6.2 产品决策，未做。
- **M 是信念级（BELIEF-LEVEL），不是读心器**：任何「已证明他心」的断言都是幻觉，故 `CONJ_OTHER_MIND_REALITY` 列为猜想并禁止进入证明链（铁律③）。deceptionBound 仅在「我方观测可区分性」下评估伪装性，不代表他心真实意图。
- **X 仍是离散图近似**：连续构型流形的离散化代价（§6.4）未消除，非线性下可达集过近似未必保守（CONJ_NONLINEAR_REACH）。
