# 灵脑推理引擎 · 原理与方法学（地基文档）

> 本文件是灵脑对外的**权威方法学说明**，对应 README 的全部能力声明。
> 它回答一个问题：**灵脑用什么方法、什么数学定理，让它能给"任意智能体"提供推理服务？**
> 所有定理名均为真实数学结果；能力名（`op`）均可在 `lingnao` 网关中直调。

---

## 0. 一句话定位

灵脑**不是**"又一个会思考的 LLM"，而是**任意智能体（无论它跑在 Claude / GPT / 自研 agent / 机器人控制器上）都可调用的确定性推理服务层**。

它通过一个**与智能体种类无关**的网关接口——MCP 工具 `lingnao`，调用形式 `{ "op": 能力名, "args": 参数 }` → 结构化结论——把下面这套数学保证交付出去。

## 1. 为什么"任意智能体"都能用（接口与确定性）

| 性质 | 含义 | 对"任意智能体"的意义 |
|---|---|---|
| **单一网关** | 只暴露 1 个工具 `lingnao`，靠 `op` 分派 51 项能力 | 任何 MCP 客户端（Claude/OpenAI/GPT/自研）一行配置即可接入，无需为某家定制 |
| **智能体无关语义** | 入参/出参都是结构化 JSON，`op` 是稳定键名 | 不要求智能体说中/英、不要求特定框架、不绑定任何 LLM |
| **确定性内核** | 同输入 ⇒ 同输出；可选 LLM 仅在"感知 NL→JSON"与"解释"两端，强制标 `UNVERIFIED_LLM` **且绝不进入推理链** | 推理结果可复现、可比对、可集成进任何决策回路 |
| **三态诚实语义** | 真 / 假 / 想不了（𝕌 弃权），fail-closed | 智能体拿到的是"可被机器消费"的结论，而非一段需要再判断的自然语言 |
| **无神经网络在环** | 推理全部是符号/数值确定性计算 | 不幻觉、不编造、不被 prompt 注入改写出错答案 |
| **内部可复现账本** | 推理链由 Hoare 逻辑闭合（proof ledger） | 任意智能体都能拿到"为什么得出此结论"的可验证轨迹 |

> 结论：**"服务任意智能体"不是营销话术，而是接口设计（单网关 + 结构化 op）与内核性质（确定性、无 LLM 在环）共同保证的。**

## 3. 各方法的数学地基（逐条）

### 3.1 深思规划（Deliberative Planning）
- **A\***：在状态图上做最佳优先搜索；只要启发式 `h` 可采纳（`h ≤ h*`），返回的路径成本最优。灵脑的 `reason` 支持系统 1 高置信快答 + 系统 2 A\* + RSG（推理状态图）。
- **确定性 MCTS（dmcts）**：选择用 UCB1（Kocsis & Szepesvári 2006），rollout 用**固定种子** ⇒ 可复现；首次访问做蒙特卡洛回溯。内部备注明确标注"此工具为近似探索层，非 KERNEL/PROOF；其结果须经 `lift_belief` 提升为信念方可进决策"。
- **值迭代 / 可达性（goal_directed）**：基于 Bellman 最优性原理的有限图值迭代，给出可达概率与最优路径。

### 3.2 因果推理（Causal Reasoning）
- **Pearl 因果阶梯**：关联（see）→ 干预（do）→ 反事实（imagine）三档，逐档信息不可从低档推出。
- **do-演算（causal_effect）**：用后门准则（Shpitser & Pearl 2006）或前门准则从观测数据识别并估计平均因果效应 ACE；返回调整集 `Z` 或中介集 `M`。
- **反事实三步法（counterfactual）**：abduction（用观测求混杂因子）→ action（设 do(X=x')）→ prediction（推 Y_x'）。
- **为何必要**：近期研究（Project Ariadne, arXiv 2601.02314）显示 LLM 因果解耦失败率 ρ≈0.77——确定性因果图正是解药。

### 3.3 不确定性理论（Uncertainty）
- **PAC + VC 维（pac_bound）**：给定 VC 维 `d_VC`、置信 `1−δ`、精度 `ε`，样本复杂度下界
  `m ≥ (d_VC·ln(1/ε) + ln(1/δ)) / ε²`。灵脑返回达到该界所需的最小样本量，让智能体知道"还差多少证据"。
- **保角预测**：marginal / pointwise 风险界为"弃权（abstain）"提供形式依据（见内部 conformal 系列自检项）。

### 3.4 数学健全性压力测试（真实定理保证，业界罕见）
这组能力是灵脑的差异化核心——用**真实数学定理**对推理结论做健全性检验，而不是启发式打分：

| `op` | 定理 | 保证 |
|---|---|---|
| `bertrand_trap` | **Bertrand 假定**（1852, Chebyshev） | ∀整数 N>1，∃ 素数 p∈(N, 2N) ⇒ 安全冗余量可证明存在（>N/2 且不超 2N）；N≤1e6 时实算 witness 素数 |
| `compactness_trap` | **紧致性 / 区间分析** | 约束族中任两项 feasible 区间两两不交 ⇒ 全局不可满足（不安全）；即开覆盖无有限子覆盖的拓扑判据 |
| `variety_trap` | **代数簇 / Zariski 拓扑** | 安全态集在采样邻接图上不连通 ⇒ 存在被隔开的不可达安全孤岛（代数几何连通性） |
| `van_der_waerden_trap` | **范德瓦尔登定理**（1927, Ramsey 理论） | 任意染色的 ℕ 必含单色 k 项等差 ⇒ 协作分配序列检出周期独占 / 结构退化风险 |
| `cauchy_lipschitz_trap` | **Cauchy–Lipschitz / Picard–Lindelöf** | 给定 Lipschitz 常数 L 与初值 x₀，初值问题解唯一（演化不分叉、可复现）；返回分离上界 `d₀·e^{L·T}` |
| `baire_trap` | **Baire 纲定理**（1899） | 观测若反复落入 meager 例外集（‖x−c‖≥normalRadius）占比超阈值 ⇒ 结构性异常（非随机波动），而非统计噪声 |
| `run_deterministic_traps` | 以上六者聚合 | 任一 unsafe ⇒ 整体 unsafe；遇 𝕌 ⇒ undecided；供内部标注"定理驱动" |

**第二辑四陷阱（2026-10-06 创造性扩展，纯 MCP 层自含实现，不依赖内核）**——面向智能体/机器人实际决策痛点：

| `op` | 定理 | 保证 |
|---|---|---|
| `pigeonhole_trap` | **鸽笼原理**（Dirichlet 1834） | n 个独占任务放入 m 个槽位且 n>m ⇒ 必有槽位承载 ≥⌈n/m⌉ 项 ⇒ 排他冲突不可避（定理级结论，无需扫描）；规划前否决不可行分配 |
| `hall_trap` | **霍尔匹配定理**（Hall 1935） | 任务-设备二分图完美匹配存在 ⟺ 每个任务子集的兼容邻居数 ≥ 子集大小。满配 ⇒ witness=匹配对；违反 ⇒ witness=亏集 S 与 N(S)（König 构造，可逐项查验）；分配可行性先于执行判定，不靠试错 |
| `erdos_szekeres_trap` | **Erdős–Szekeres 定理**（1935 单调子序列） | 长 n>(k−1)² 序列必含长 ≥k 单调子序列 ⇒ 检出行为/性能序列（延迟、错误率、资源占用）的结构性单调漂移——结构性趋势而非随机波动；定理保证存在但扫描未得时诚实弃权 𝕌（陷阱自检） |
| `euler_path_trap` | **欧拉路径定理**（Euler 1736，哥尼斯堡七桥） | 连通图存在"每边恰一次"路径 ⟺ 奇度顶点数 ∈ {0,2} ⇒ 全覆盖巡检/扫勘/走线路线可行性判定；unsafe 时给奇度顶点清单/断开分量 + 最少巡检链数 |
| `run_deterministic_traps` | 十陷阱统一聚合 | 第二辑四陷阱随 args 可选并入内核六陷阱聚合：任一 unsafe ⇒ 整体 unsafe；有 𝕌 ⇒ undecided；向后兼容（不传新参数 ⇒ 行为与旧版一致） |

### 3.5 世界模型 / 反事实 / 元认知 / 自演化
- **结构方程模型 SEM（world_model）**：线性 SEM 做状态转移与反事实模拟。
- **Banach 不动点定理（perceive_belief）**：感知信念更新被构造为收缩映射（contraction），`contractionL < 1` ⇒ 迭代收敛（`converged=true`），给收敛保证而非"希望它收敛"。
- **Hoare 逻辑（proof_ledger / audit-proof）**：推理链以 `{P} C {Q}` 部分正确性证明闭合，自检项验证 Hoare 字符串非空且推导链闭合。
- **形式概念分析 FCA / Galois 连接（knowledge_*, cog_graph）**：知识以形式概念格组织，保证概念外延/内涵的单调性。
- **经验库生命周期（sl_*）**：科学发现循环——记录（sl_record）→ 发现（sl_discover）→ 验证（sl_validate）→ 监控（sl_monitor）→ 状态（sl_status）。
- **IMA 数学库（ima_load / ima_query）**：431 条数学模块 / 102 个索引，作为推理的可引用定理源。

### 3.6 具身决策（Embodied）
- 声明式能力契约接入任意身体；规划 → SAFE-STOP 安全检查 → 执行 → 有界重规划（`maxReplans`）闭环，保证"想干"与"能安全干"分离。

## 4. 诚实边界（不虚报）

| 项 | 实情 |
|---|---|
| 因果 / 世界模型 | **lite 实现**：PC-lite 因果发现、线性 SEM；规划基于有限图 |
| 但每个结论 | 来自**确定性符号计算**，可复现、不幻觉，且数学健全性由**真实定理**保证，不是启发式打分 |
| 不保证 | 绝对安全、绝对正确、不漏解、能连所有真机（设计上的诚实边界，非待修缺陷） |
| 验证/审计 | `audit`/`certify`/`verify`/`prove`/`runtime_monitor` 等已从**对外网关能力清单移除**，仅留为内核内部资产；灵脑对外只做推理 |

## 5. 与灵数的分工

- **灵脑 = 推理**（本文件所述一切）。
- **灵数 = 计算**：方程组实数解（区间收缩 + Krawczyk 认证）。`algebraic_solve` **委派**给灵数真引擎，灵数是**可选依赖**——不装它，其余能力照常，仅该项诚实降级。
