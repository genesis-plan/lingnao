# 09 · 项目历史

> 版本级变更记录见 [08 · 版本管理](08-版本管理.md)。

## 一、定位沿革（一句话版）

**从"想要一个通用大脑"，收敛到"先把大脑里可证的那部分证明出来"。**

| 阶段 | 想做什么 | 落到什么 |
|---|---|---|
| 起点 | 通用大脑：图论本体 + 分层认知框架 + 形式化定义 | 概念先行，但缺可验证内核 |
| 第一次收敛 | 让大脑有"世界"：世界图 + A\* 最优决策 + 审计 | 可跑的单文件内核 `灵脑.html`，零依赖 |
| 第二次收敛 | 让大脑"说得清凭什么"：七段审计 + 霍尔证书 + 依据链 | 审计报告与证明证书成型 |
| 第三次收敛 | 让大脑能干活：具身层（能力契约 + SAFE-STOP 安全闸） | 规划 / 执行 / SAFE-STOP / 有界重规划闭环 |
| 第四次收敛 | 让大脑接得进现实设备：物理接入模块（翻译壳） | 30 协议登记 + 17 规范卡 + 9 类解码器 |
| 当前阶段 | **把可证的部分真正证出来**：形式化证明模块 M1–M4 | M1–M4 落地，且**如实标出各自边界**（M2 带松弛、M1/M4 为静态检查、副作用面完备性不成立） |

> 早期"烛照"证明引擎路线已退休，其**"公理驱动 + 依赖图可审计证明"**的思路被灵脑继承，
> 但**换了形态**：不再是独立引擎，而是内核里可机器检验的门控链与数值证书。

## 二、关键决策记录（为什么走成现在这样）

| 决策 | 时间 | 理由 | 后果 |
|---|---|---|---|
| **不引入神经网络** | 全程 | 计算图不可解释、结果不可复现，与"可审计"目标冲突 | 内核零依赖、确定性；语言能力改为**外挂 LLM 感知层**，并强制标 `UNVERIFIED_LLM` |
| **代数求解委派灵数，不自己写** | 接入灵数时 | 同一能力两套实现必然漂移 | `algebraic_solve` 走真引擎（区间收缩 + Krawczyk 认证）；缺依赖时**单项诚实降级** |
| **单一真源 + 三面导出** | 架构定型 | 内核/服务/浏览器三处代码各写一遍必然分叉 | `灵脑.html` 为唯一真源；`__WB` / `__exp` / `EXPORT_NAMES` 三面必须逐名一致 |
| **fail-closed 而非 fail-open** | v1.1.0（#246） | 审计账本用随机密钥启动 = 本进程可伪造条目 = 账本无效 | 缺密钥**拒启**；`insecureAudit:true` 为带可见告警的开发逃生口 |
| **许可由 UNLICENSED 改为「非商业免费 + 商业授权」** | v1.1.0（用户决策） | 原状态与"面向 AI Agent 免费分发"自相矛盾 | 合规缺口补上；非商业免费范围写死在 LICENSE 第二条 |
| **不用"全绿"报结果** | v1.1.1（修 1） | 6 项 KB 能力确实没接入，说"全部通过"就是假绿 | 自测改口径为"核心 N 项通过 + 已知未实现 M 项" |
| **把不完备性登记进内核** | 形式化阶段 | 任何系统都有理论边界，含糊才是风险 | 内核含 `THM_GODEL_INCOMPLETENESS`；对外不称"数学上不可越狱" |
| **设备接入以"翻译壳"收口** | 接入模块 | 复制对方内部系统既侵权又不可维护 | 只产规范语义映射层；黑盒设备走 `needsAnchor` 人锚 |

## 四、命名说明（历史遗留，别误会）

仓库里存在几个**历史命名残留**，它们不是 bug，是为兼容老配置保留的：

| 残留 | 含义 |
|---|---|
| `LINGJING_HTML` / `LINGJING_MEMORY` 环境变量 | 本 MCP 早期曾以"lingjing"命名，后定名**灵脑 LingNao**；旧名作为兼容别名保留 |
| `.lingjing-memory.json` / `.lingnao-memory.json`（`.gitignore`） | 运行时记忆存档（**非源码**），两个名字都忽略 |
| `灵脑.html` 内文件名/变量含 `WB`（`globalThis.__WB`） | 内核自暴露命名空间，历史沿用 |

**注意**：`灵境 LingJing` 是**另一个仓库的另一个产品**（`genesis-plan/lingjing`），与灵脑不是同一件事。
详见 [01 · 产品作用](01-产品作用.md) 第七节与 README 的"两个独立产品"说明。

## 五、方向已定但未做（诚实待办）

| 方向 | 现状 | 卡在哪 |
|---|---|---|
| **接入 KB 知识库** | 6 项能力（`kb-summary` / `knowledge_query` / `knowledge_add` / `knowledge_ann` / `knowledge_distill` / `cog_graph`）恒返 `available:false` | KB（经验库 / LSH / FP-Growth / 认知图谱）为可选依赖，尚未接入 |
| **通用协议真实驱动** | 30 条协议中 27 条"仅建档" | 需硬件（PROFINET / EtherCAT 网卡、CANopen 主站、表计串口等） |
| **8 类数学实装** | 未实装 | MPC、SOS/SDP 障碍证书、一般 LP 求解器、一般非线性可达集等 |
| **副作用面完备性** | **不成立**（受控 1 / 未受控 18） | 需把 HTTP 外发与本地持久化也纳入门控作用域 |
| **`module/math-model.js`** | 已知缺陷：`require('./virtual-world.js')` 指向不存在文件 | 模块未完成；不在 npm 发布清单内 |
| **源码 / 部署形态** | 本地嵌入与私有化可用 | 大规模服务化、分布式运行不在当前路线 |
| **商标与专利检索** | 暂缓 | 优先级低于获取首个具名商业授权案例 |

## 六、一句话总结这段历史

> 灵脑这一路做的事，可以概括成一句：
> **把"说得清"从口号变成可执行的东西 —— 能确定的做成检查，不能确定的写在返回值里。**

这条线决定了它所有的取舍：不引神经网络、不重写求解器、不用"全绿"报结果、
把松弛和未实现都写进文档与合同。
