# 灵脑数学第一性原理审计

> 目的：从第一性原理（产品的立身之本＝确定性可审计 + 不可逆伤害不可约 + 不幻觉）倒推每个模块「该用什么数学」，再对照内核现状（灵脑.html，逐行核实），给出**保留 / 修改 / 组合**的判定。
> 审计范围：内核全部数学构造（八元组、LCF-架构、量纲、观测、动力学 f、信念 B、价值 V、因果、不变量、他心、自主等级、安全闸）。
> 方法诚实声明：本报告先**核实代码再下结论**，已纠正一份早期总结里的误读（见 §2-B）。

---

## 0. 总判（独立判断，不捧）

灵脑的数学骨架**异常成熟且内部一致**，远超多数从零搭建的产品。其选型与世界前沿对齐良好：

- 不精确概率（Dempster–Shafer 包络，`beliefPlausibility`/`decideImprecise`，4730-4763）
- 混合自动机（`hybridAutomaton`/`hybridStep`/`hybridReach`，3128-3193）
- 信号时序逻辑定量语义（STL robustness degree ρ，2783 / 1853-1899）
- 区间可达性（SAFE/UNSAFE/UNKNOWN，4598-4655）
- 控制障碍函数 CBF + Lyapunov（2515 / 2704-2723）
- Kalman 滤波 + 粒子滤波（3513 / `particleFilterStep` 5387）
- do-calculus 可识别性（Tian–Pearl `identifiabilityID`，1494-1513）+ PC-lite 因果发现（1483-1489）
- 香农信息增益主动感知（`expectedInfoGain`，3744）+ PAC 样本界（1478-1482）
- Buckingham π 量纲（已落地）

**真正系统性短板只有一个：不确定性被算出来了，却没端到端传播进确定性决策路径。** 各个"该改"的建议都是这条主线的分支。下面逐项确认，并指出哪些是"保留别动"、哪些是"组合复用现有数学即可补齐"。

### 1.1 八元组形态 𝔹（5141-5301）—— 保留，仅改 f 类型
八元组作为**数学签名/规格**是对的。它表达的是"大脑有哪些不可约的部件"，不是定理，不必机检。第一性原理的不可约性（4 个建模目标 + 不可逆伤害不可约）推导成立。
**唯一要改的**：`f` 在签名与注释里写成 `f: X×U→X`（5165）。从第一性原理，一个**世界模型**是**非确定**的——同一状态同一动作可有多个结局（扰动、他者、未知）。函数签名隐含**闭世界假设**。应改为**部分非确定转移关系** `f ⊆ X×U×X`（或 `f: X×U ⇸ X` / `f: X×U → ℘(X)`）。当前三分支实现已接近此意，只是类型标注与"学习 f 返回单点预测"没显式表达非确定性。

### 1.2 LCF-架构内核（3931-3950）—— 保留
COMPUTE（galoisCheck 36 样本 / verifyHeuristicConsistency 机验）+ DERIVE（存证可溯、字符串不被小证明核机检）的拆分是**诚实且达标**的。铁律③（猜想永不入证明链）是"不幻觉"最硬的形式化，正确。
**长期项（非现在）**：DERIVE 的 `check` 闭包目前不被小证明核强制机检，TCB=JS运行时+check闭包。按 De Bruijn 准则，最终应把 DERIVE 也机检以缩小 TCB。优先级低，不影响对外诚实口径（已正确降级）。

### 1.3 量纲 Buckingham π（已落地）—— 组合：补守恒律
π 定理正确，能抓**量纲/单位**错误。但"物理正确性"还含**物理定律**正确性：错误受力模型（如违反能量守恒）量纲仍可对。第一性原理补强：增加**守恒律不变量**（能量/动量/角动量，Noether 对应连续对称）。这把"物理安全包线"从"单位对"升级到"定律对"。**仅当物理推理是产品目标时做**，否则过度。

### 1.4 观测 h + 可区分性（5154-5164 / 4772-4795 / 3513 / 粒子滤波）—— 保留
`h` 逐传感器投影 + Kalman 滤波（`matInv` Riccati，3582）+ 粒子滤波（`particleFilterStep`）已是**测度论**的观测处理（后验分布）。布尔 `distinguishable`（4772）是在滤波之上的**决策层**近似（"两态在传感器推前测度下是否不可区分"），可接受。若细化：可区分性应定义为推前测度之差（总变差/ KL），而非布尔；属锦上添花。

### 1.5 动力学 f（5165-5193）—— 改（类型 + 候选集）
现状三分支诚实且分层正确（图边/具身→KERNEL；学习→PERCEPTION 禁入证明链；无→𝕌）。
**第一性原理缺口**：
- (a) 类型签名是函数，应是非确定关系（见 1.1）。
- (b) 当"图边"与"学习 f"**并存**或"学习 f"本身不确定时，`f` 应返回**候选集 + 各自信念**（非确定转移关系的实现），而非 `predicted: sim.next` 单点。否则稳健规划拿不到"可能的多种后果"。
- 这直接喂给 §2-A 的端到端不确定性传播。

### 1.6 信念 B（5269-5295 / 4730-4763 / 1219-1308）—— 组合：统一到 D-S 包络
内核里有**两套**信念表示：
- `BrainTuple.B(candidates)`：加权候选 + Shannon 熵（5269-5284）—— 单层、点估计式。
- `beliefPlausibility`/`decideImprecise`：标准 **Dempster–Shafer 不精确概率** `[belief, plausibility]` 包络（4730-4763）—— 这才是处理"我们诚实不知道"的正确数学（宽度=不确定性本身，𝕌 可量化）。
- 还有 `perceiveBelief`（贝叶斯滤波 + Banach 收缩界，1219）、`reconcile`（KL-I-投影，1274，即 credal set 更新）、粒子滤波。
**判定**：数学都对了，但**没接起来**。`BrainTuple.B` 应直接暴露 `belief/plausibility` 包络（复用 `beliefPlausibility`），而非另起一套加权候选。这是**组合/接线**，不是新发明。

### 1.7 价值 V（5211-5230 / 5313-5317）—— 组合：稳健/不精确可达性
**关键纠偏**：我此前一份总结里把 V 说成"reward 最大化"。核实代码后这是**误读**——`V()` 是**可达性值迭代**（goal=1，对 children 取 `max` 传播，5220-5226），MCTS 的 reward 是二值"到达/未到达"（1460）。这与叙事"无 reward/utility 最大化"（2342）**一致**：目标是"是否存在安全路径到达目标"，不是"在结果间按偏好最大化效用"。**所以 V 的选型正确，无需改方向。**
**真正缺口**：V 是**脆**的 0/1（或确定图上的 reach 概率），**不吃不确定性**。当 f 是 PERCEPTION（学习，不确定）或 B 非退化时，某个状态的"能否安全到达"应是一个**不精确概率包络** `[bel_reach, plaus_reach]`，而非脆值。即应升级为 **稳健/不精确可达性**：`V: X → [belief, plausibility]`，由 B 的包络 + f 的候选集推出。这复用 §1.6 的 D-S 包络与 §1.5 的关系化 f——正是 §2-A 主线的落点。

### 1.8 因果 SEM / do-calculus（1494-1513 / 1755-1800 / 1483-1489）—— 保留
框架正确：线性 SEM-lite（诚实标 lite）+ 前门/后门调整 + Tian–Pearl 可识别性判定 + PC-lite 因果发现（1483）。因果假设（faithfulness/无环/因果充分性）已在 C 项显式暴露为 `CAUSAL_ASSUMPTIONS`（挂到 `causalEffect` 输出）。非线性/ANM 可识别性为远期增强，当前"lite 等价、可审计"口径诚实。

### 1.9 不变量 Inv（5231-5236 / 4598-4655 / 2783 / 2515 / 2704）—— 保留（标杆）
区间可达性（SAFE/UNSAFE/UNKNOWN，诚实 UNKNOWN）+ STL 定量鲁棒度 ρ + CBF + Lyapunov 四者**互补且都正确**。这是产品最强的数学段，别动。

### 1.10 他心 M（5241-5265 / 5318-5325）—— 改（仅当 ToM 是目标）
现状：单层贝叶斯信念（他 agent 的后验）+ 可区分性伪装界（`deceptionBound`）。第一性原理的"心智理论"需要**嵌套信念**——"我相信你认为我相信…"，即认知模态逻辑 **KD45** + 公共知识。当前是单层的。若产品目标含多智能体博弈/欺骗识别，应加嵌套信念层；否则（纯单智能体执行）单层足够，保留。

### 1.11 自主等级 AUTONOMY（D 项落地）—— 保留
L0–L5 格 + 按风险触发 HUMAN-IN-THE-LOOP，正确（有序集/格即恰当数学）。IRREVERSIBLE-HALT 最高优先保留。

### 1.12 安全闸 IRREVERSIBLE-HALT（execute 四道 fail-closed）—— 保留
语义等价于"可达坏集"的形式化验证（reachability to bad set）+ 障碍证书（CBF）。正确且最高优先。

## 2. 跨模块系统性发现（核心）

### 2-A（主线）不确定性是"侧信道"，没端到端传播
内核**算出了**不确定性（B 的 D-S 包络、粒子滤波、学习 f 的 PERCEPTION 标注、STL 鲁棒度、区间可达 UNKNOWN），但**确定性决策路径**（规划 V、执行 gate）多数只吃**确定性分支**：
- `f` 学习分支返回单点 `predicted`（5191）——非确定后果被压成一点。
- `BrainTuple.B` 用加权候选而非 D-S 包络—— richest 的不精确概率没进八元组。
- `V` 是脆可达（5220）——不吃 B/学习 f 的包络。
- `decideImprecise`（最正确的不精确决策器）只在 `beliefPlausibility` 旁孤立存在，没被规划环路调用。

**第一性原理结论**：一个"不幻觉"的大脑，其决策必须**显式承认并利用**自己的不确定性边界，否则"脆可达"在未知动力学下会**过度自信地下发危险动作**。修法不是发明新数学，而是**把已存在的不精确概率包络做成贯穿 `f → B → V → execute` 的一等公民**（组合）。

### 2-B（纠偏）"无 utility 最大化" 与 V 一致
核实 `V()`（5211-5230）与 MCTS（1450-1475）后确认：V 是可达性值迭代、reward 二值。叙事"无 reward/utility 最大化"成立，**此前把 V 归为"期望效用最大化"的总结是误读**，本报告更正。这一点反而是产品的优点（目标导向而非偏好导向，契合安全关键）。

### 2-C 两套信念表示并存
`BrainTuple.B`（候选+Shannon）与 `decideImprecise`（D-S 包络）应统一。见 1.6。

### 2-D f 应是非确定转移关系
见 1.1 / 1.5。类型签名与"并存多源"时的返回形态都要改。

## 4. 结论

- 八元组形态成立且不可约；各模块数学选型与世界前沿对齐良好（不精确概率、混合自动机、STL、区间可达、do-calculus、CBF/Lyapunov 都是对的），**这些保留别动**。
- 唯一真系统性缺口＝**不确定性没端到端传播**（f 单点 / B 未接 D-S / V 脆可达 / decideImprecise 孤立）。
- 补法＝**P0 组合**：把已存在的不精确概率包络做成贯穿 `f→B→V→execute` 的一等公民，**复用现有数学，不新发明**。
- 另两项"改"是 P1（f 类型关系化、B 接 D-S），属 P0 的子集；P2/P3 依产品目标取舍。
- 方向你定，我不替拍板。我的独立判断：**P0 最划算**——零新数学、纯接线与类型统一，却能补齐"不幻觉"在开放世界的最后一环。
