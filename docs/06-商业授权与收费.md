下列行为**一律需要**版权方签署的书面《商业授权协议》，未获授权即属侵权：

- 将本软件用于任何**以营利为目的**的产品、服务或业务；
- 通过 SaaS、云部署、API 或任何其他方式，**向第三方提供**基于本软件的能力（**无论是否收费**）；
- 将本软件**集成、嵌入或捆绑**进任何商业发行物、设备或解决方案；
- 对本软件进行**再分发、转授权或对外提供托管**；

未经书面授权的商业使用构成侵权，版权方保留追究全部法律责任（含停止侵权、损害赔偿及诉讼费用）的权利。

## 四、授权内容可以包含什么

灵脑面向的是"**决策要说得清**"的落地场景，因此商业授权通常围绕下列要素组合
（**具体范围以双方签署的书面协议为准**）：

| 要素 | 说明 |
|---|---|
| **使用许可** | 非独占、不可转授权的年度使用许可，约定用途、地域、期限与实例数 |
| **嵌入授权** | 允许将内核集成进乙方自有产品 / 设备，并以乙方品牌对外呈现 |
| **私有化交付** | 交付可离线运行的内核与部署说明（自有 LICENSE 约束仍适用） |
| **认证报告** | 针对乙方场景出具的形式化验证结论说明（M1/M2/M4 的结论与**其边界**一并写明） |
| **安全栈适配** | 按乙方物理载体定制能力契约、安全约束与 SAFE-STOP 规则 |
| **技术支持 / SLA** | 响应时限、版本通知、缺陷修复期限 |
| **白标 / 源码托管** | 仅在更高档位按《技术交付附录》单独约定 |

**价格**：按用途、部署方式（本地嵌入 / 私有化）、实例数、SLA 要求与是否含定制评估来定，
**以书面报价与签署合同为准**（可按需提供报价单）。当前**没有公开价目表** —— 不以虚构数字对外承诺。

## 九、常见问题

**Q：我自己用 / 教学用，要付费吗？**
不用。非商业使用免费（第二节），npm、克隆、网页三个形态都免费、不限次数、可离线。

**Q：我在公司内部评估，算商业使用吗？**
年营收 ≤ 100 万元、仅内部评估、同时运行实例 ≤ 3 个，属免费范围；
**一旦用于营利业务或对外提供能力，就需要商业授权。**

**Q：能不能先免费试，再决定买不买？**
可以。npm 形态可完整验证能力（免费、不限次数）。
需要定制能力契约、私有化交付、认证报告与 SLA 的，属授权范围。

**Q：灵脑能保证"绝对安全"吗？**
不能，也不这么宣称。M2 证书带 `h ≥ −1/B²` 辅助域松弛；M1/M4 是静态/语法层检查；
副作用面完备性**当前不成立**。我们提供的是"**可验证的部分盖章 + 不可验证的明说**"。
如果采购方需要"绝对安全"的书面背书，请先理解这一点再谈 —— 我们不签做不到的承诺。

**Q：商业授权能不能拿到源码？**
视档位。默认交付可运行内核与部署说明；源码托管 / 白标属更高档位，按《技术交付附录》单独约定。

**Q：你们会收集运行数据吗？**
不会。本地 / 私有化形态完全离线；网页形态数据不出浏览器。见 [04 · 技术参考](04-技术参考.md) 第八节。

**Q：许可证以后会变吗？**
本软件自 v1.1.0 起适用本《商业授权许可协议》（此前为 UNLICENSED 状态）。
许可变更不溯及既往地赋予新权利。历史见 [08 · 版本管理](08-版本管理.md)。
