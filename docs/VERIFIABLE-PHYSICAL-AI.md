# 可验证物理 AI — 灵脑的定位与机制

> 本文回答一个问题：当产业界说"物理 AI 落地的最后一公里是可靠性"时，
> 灵脑在这条路上到底站在哪个位置、提供了什么别人没给的东西。

---

## 一、产业界给物理 AI 划的三道门槛

据 2026 世界机器人大会，清雁科技提出「几何物理驱动的物理 AI 基础设施」框架，
指出物理 AI 走向真实世界必须跨过三道门槛：

| 门槛 | 含义 |
|---|---|
| **泛化性** | 能否适应训练时未见过的设备、场景、任务 |
| **可靠性** | 能否保证不出事 —— 这是最硬的一道 |
| **持续学习** | 能否从真实运行中持续改进而非一次性部署 |

他们的核心判断是：**可验证学习（用可验证的方式检验世界模型的预测）是突破可靠性的关键。**

这个判断与灵脑的设计哲学高度一致，但两者切入的角度不同：
产业界从"模型"入手，灵脑从"**调度与校验中枢**"入手。

---

## 二、灵脑的对应位置

灵脑不做模型，做的是**模型与物理世界之间的可验证校验层**。三道门槛的对应关系：

| 门槛 | 产业界常见做法 | 灵脑的机制 |
|---|---|---|
| **泛化性** | 扩大数据、预训练、微调 | **契约接入** —— 不训练、不微调。设备签署契约（状态/控制/资源/观测）即可接入，大脑不内含任何具体身体的知识 |
| **可靠性** | 行为克隆 + 安全护栏 + 人工兜底 | **可验证性** —— A\* 最优性保证、区间约束、量纲齐次性、观测可区分性，四层叠加 |
| **持续学习** | 在线微调（有灾难性遗忘风险） | **SelfLearn** —— 只更新置信度与经验，不改动证明链；学习结果不进入 PROOF 档 |

关键差别在于：**产业界的可靠性是"测出来的"，灵脑的可靠性是"证出来的"。**

## 三、本次补上的拼图：量纲分析（物理正确性约束）

### 3.1 前沿动向

以 Phaethon 为代表的端到端框架，核心主张是：
**确保数据和模型从输入到输出严格遵守物理量纲（单位制），从"物理正确性"上对 AI 进行约束。**

此前灵脑只有**区间约束**，它能保证数值不越界，但保证不了数值说得通。
举例：

- 区间约束能拦住「速度 200 km/h」（超出 120 的上限）
- 区间约束**拦不住**「速度 200 秒」（单位根本就不对）

后者是物理上荒谬的，但在纯数值区间里完全合法。

### 3.2 灵脑的实现

已落地于内核（`灵脑.html`），零依赖：

**量纲代数** —— SI 七个基本量纲 `[L, M, T, I, Θ, N, J]` 的向量运算

```
dimMul / dimDiv / dimPow    乘除幂 → 向量加减与数乘
dimAdd                       加减 → 受量纲齐次性约束，不同量纲返回 null
dimFormat                    可读输出，如 L²MT⁻³
```

**量纲齐次性** —— 只有同量纲的量才能相加。这不是风格建议，是物理定律。

**带量纲的值** —— `{v: 数值, dim: 量纲名}`，在写入字段时与字段声明比对：

```js
// 字段声明 position 为 LENGTH
effect: { inc: { position: { v: 3, dim: 'TIME' } } }
// → 拒绝：字段 pos 声明为 L，却赋了 T
```

物理上荒谬的动作在**规划阶段**就被判定不可用，根本不会进入执行。

**Buckingham π 定理** —— `n` 个变量、量纲矩阵秩 `r` ⇒ `n−r` 个独立无量纲积。
用途是**校验物理模型是否遗漏了关键变量**：π 项数量不对，说明模型量纲不完整。

已验证的经典案例（单摆）：

```
变量：T(周期) / L(摆长) / g(重力加速度)
3 个变量，量纲矩阵秩 2 ⇒ 1 个无量纲积
π = T² · L⁻¹ · g¹  →  T = f(√(L/g))
```

这与单摆周期公式 `T = 2π√(L/g)` 的无量纲结构完全一致。

### 3.3 与区间约束的分工

| | 区间约束 | 量纲约束 |
|---|---|---|
| 保证什么 | 数值不越界 | 数值说得通 |
| 数学基础 | 区间分析 / 约束传播 | 量纲代数 / Buckingham π |
| 拦住的错误 | 速度 200（超上限） | 速度 200 秒（单位错误） |
| 失败方向 | 保守（可能误拒可行任务） | 确定（量纲不匹配必是错误） |

**二者正交，缺一不可。** 区间管"多少"，量纲管"是什么"。

## 四、为什么这是"最后一公里"

产业界现在缺的已经不是"能不能做"，而是"**敢不敢用**"。

一个具体的对照：

- **MHS（Anthropic, 2026-08-27）** 解决了「连得上」—— 设备接入从数周压到数小时。
  但它的安全机制是**设备级静态阈值**：检查 `u ≤ u_max`，点式、单设备、不看动力学。
- **QuEra 案例**：Claude 无人值守迭代几百次，把激光恢复成功率从 58% 提到 99.3%，
  恢复时间从 150 秒降到 6–14 秒。这个数字很漂亮，但它是**试出来的**，不是**证出来的**。

99.3% 意味着 700 次里有 5 次失败。实验室可以接受，产线和临床不行。

灵脑要提供的正是这个缺口：

> 不保证"一定能找到解法"，但**要么给出可验证的证明，要么诚实标记 𝕌（不可判定）**。

这恰好对应灵脑既有的四档降级链：

```
proven     → 找到 barrier certificate，形式化证明
certified  → 可达集过近似完全落在安全集内
likely     → 采样验证 + PAC bound
𝕌          → 诚实标记不可判定，不猜测
```

**「不假装知道」本身就是产品特性** —— 对科学仪器与工业控制而言，一个会说"我不知道"的系统，
比一个 99.3% 自信的系统更可用。

## 五、诚实的边界

以下都不是灵脑当前能做到的，写在这里以免高估：

1. **可达性判定存在理论硬边界** —— 半代数集路径连通性是 PSPACE-hard；
   一般非线性动力学系统的可达性**不可判定**。灵脑用区间过近似做 sound 的保守判定，
   代价是可能产生假阳性（认为可行实则不可行）。
2. **量纲检查不是语法糖** —— 它只能拦住"单位写错"这类错误，
   拦不住"单位对但数值在物理上不合理"（例如 0.001 m/s 的搬运速度）。后者仍要靠区间。
3. **状态空间不是半代数集** —— 含 sin/cos 的机构（机械臂正运动学）不是半代数集，
   Tarski-Seidenberg 不适用。灵脑改用**区间保守外包络**，sound 但不 exact。
4. **高维不可处理** —— 可达集过近似在 6 维以上急剧膨胀，与 lingshu-solver 的 ≤6 变量限制同源。

## 六、一句话

> MHS 让 AI **够得着**设备；量纲分析保证它**说得对**；区间与观测契约保证它**证得出**。
> 三者合起来，才是"敢让 AI 碰物理世界"的完整答案。
