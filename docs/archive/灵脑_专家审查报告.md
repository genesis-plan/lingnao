## 〇、总裁决

| 维度 | 结论 | 一句话 |
|---|---|---|
| 架构 | 内核扎实、外围散装 | 分层单向、无循环依赖；但"可组合引擎"实为"共用一个全局单例"，模块各自编排、契约分裂 |

## 二、① 架构审查

**整体**：分层方向单向（能力模块 require 内核），无循环依赖；诚实边界文档自认"五层整体未开始"，值得肯定。但"可组合引擎"在代码层面**不成立**——组合实际是"共用一个全局对象"。

- **P1-1 能力④绕开内核大脑**：math-model 自实现 Dijkstra+贪心，核心推理完全绕开内核 reason/aStar；且"最小代价最大流"措辞不准（实为运输问题贪心）。
- **P1-2 编排逻辑重复**：`runBrainCycle`（virtual-world）与 `runMathCycle`（math-model）整段复制；robot-fleet 与 math-model 内置同一支机队数据。→ 编排上移为独立 orchestrator，模块只注册策略。
- **P1-3 蒸馏引擎反向写内核**：`L.KnowledgeDistillery = Engine` 污染内核命名空间，依赖方向被破坏；且其审计结构与 `generateAudit` 完全不同 → "统一可机读审计协议"存在两个方言。→ 删除回写，审计改调内核。
- **P1-4 内核以 81KB 字符串内嵌执行**（vm.runInContext）：不可 lint、堆栈行号无意义、与 lingnao-mcp.js 两份内核字符串必然漂移。→ 内核写独立源文件，构建期打包。
- **P2**：vm 注入完整 `process`/`fetch` 隔离形同虚设；`applyTransfer` 不校验库存可透支可负数；测试即 demo（断言写在 `require.main` 块，无 CI）；`coordinateResources` 盲选 `direct[0]` 供应商。

**架构 3 条关键改进**：① 审计 fail-closed（生死线）；② 内核实例化 + 依赖注入，联邦跨序列化边界验证；③ 契约先行——为 setWorld/reason/generateAudit/EventBus/KB 定义单一 JSON Schema + 契约测试，统一 emit/publish，清除裸 `catch(_)`（本次发现两模块对同一内核分别用 `emit` 和 `publish`，至少一半事件被静默吞掉）。

## 三、② 代码质量审查

**旧 bug 复核**（4 修 1 未真修）：

| 旧 bug | 结论 |
|---|---|
| 财务 ACE 错标 | ✅ 已真修（前门分支实装，实测 ACE=120000 与数据一致）；但 `lingnao-finance-demo.js:60` 的 `: 120000` 硬编码兜底残留，出错时静默冒充计算结果 |
| 蒸馏"只存不拆" | ✅ 已真修（stepify→localize→verbalize 真执行） |

**主要新发现**（P0 见总表；P1/P2 摘要）：
- P1：内核 `0.5+0.1×3=0.7999…` 浮点使 system1 的 `>=0.8` 阈值第 3 次更新意外不触发（实测踩中）；`reproducible.ts`/`reportId` 含时间戳，"复现指纹"每次运行都不同；蒸馏分隔符交替序使 `应该`/`遇到` 不可达（被前缀抢先）；寻路失败代价默认填 `1` 冒充实测值；后门分支缺变量静默补 0 = 编造观测。

**代码 3 条关键建议**：① 约束单一真源（hard 线程化到底）；② 贪心换最小费用流或改口"启发式"+ 证伪性对照测试；③ 审计诚实化（输入形状校验、`proof.hoare` 仅在 `verified===true` 时输出、删伪造 valid、断言改查 `proof.verified`）。

## 四、③ 功能与诚实边界审查

**「不幻觉」真实度评分**：

| 层 | 评分 | 依据 |
|---|---|---|
| 内核 GROUNDING/审计机制 | **7.5/10** | 三档真被赋值；reason 结果霍尔验证逐边不变量为真；perceiveLLM 离线诚实 401、askBrain 降级 ok:false |
| 演示/输出包装层 | **4/10** | 对未验证证明打 ✔；catch 兜底伪造 valid；蒸馏审计无条件 valid |
| 对外声明（README/社区帖） | **6/10** | 45/45 实跑为真、lite 边界已标注；但"大模型"定位、因果话术过度 |

**逐项核验**：
- GROUNDING 三档：**真**（PERCEPTION 明言"绝不进证明链"且 mayHallucinate=true）。
- perceiveLLM 隔离：**成立**（federation 以 `!perceived.ok` 闸死自主动作，构造上感知层不进证明链）。
- math-model：升序贪心对**可分无容量**运输问题确实最优、Dijkstra 正确、禁自环生效——但一般运输问题无最优性保证（见 P0-5 反例）。
- robot-fleet：电量只是名字字符串，不在 resources/needs 模型里——"电量不凭空转移"是**空洞真**（无电量动力学，谈不上转移）；数据系编造但已双处声明"公开资料简化建模"，不算虚构；45/45 实跑不虚报。
- knowledge-distillery："任意领域通用"成立但是**字符串级通用**（中文正则+词典替换，文件头已自认"启发式非真NLP"）；confirmStep/reportFailure 升降档真生效；**但 reportFailure 的 KB 降级被 `basis!=='expert-testimony'` 门挡死，而 distill 产出的步全是 expert-testimony → "知识可逆降级"在真实路径从未发生过**。
- finance-demo：前门准则识别为真实现，但 4 个样本是按假设线性模型手工编造的——**用假设数据自证假设**；"36000 元"是制造的，不是估计的。这是给"不幻觉"招牌埋雷。
- README："可审计确定性推理大模型"定位话术过度——它是带审计的确定性图推理引擎，不是"模型"。

**诚实边界 3 条改进**：① 全链路 fail-closed；② 蒸馏审计分级 + reportFailure 对 expert-testimony 生效（以 manualId+stepId 为 KB 键）；③ 文案与代码对齐（finance 明标"合成数据仅演示机制"、删"最大流""大模型"措辞）。

## 五、④ 产品/市场契合审查

**整体判断：这是技术演示，不是能卖的东西。** 内核工程是真的、严谨的；但所有 demo 的输入都是手搓的假数据——在一个假村庄/假机队/假账本上跑出"可审计最优解"，离客户付费还差一个真实世界。更致命的是定位：**"通用大脑"没人买，企业买的是"某个具体问题的可审计解法"**；且对外 MIT 免费、面向 Agent 白送，与"30 天变现金"直接矛盾。

**变现紧迫度排序**：

| 顺位 | 模块 | 判断 |
|---|---|---|
| ① | **知识蒸馏** `knowledge-distillery.js` | **唯一接近真需求，先做**。离线能跑、无需 API key，把专家隐性经验变成带可信档的可复核 SOP。买家清晰：安全培训/SOP 部门、NGO 田间推广、制造质检、受监管行业。30 天内唯一可能换钱的切片 |
| ② | 联邦审计 | 留作技术储备，不卖（今天零客户零生态） |
| ③ | 虚拟空间 / 数学建模 | 砍展示、留内核（手工画的图上跑运输问题，教学玩具） |
| ④ | 机器人机队 | **砍，且是信誉风险**——"与真实部署同代码"措辞会被懂行的戳穿（零真数据、无 ROS、无实时） |
| ⑤ | 个人财务 | **砍，最该藏起来**——把"找朋友借钱"当首付最优路径、损耗权重瞎编、"前门因果"在合成数据上自证；用霍尔证明给这种建议背书是在消耗"不幻觉"招牌 |

**最弱一块**：没有真客户 + 没有真数据接入 + 没有部署路径 + 没有收费模式。叙事悬浮在愿景层——README/社区帖全在讲"不说谎的通用大脑"，没一句话讲清"卖给谁、解决什么具体问题、花多少钱、怎么部署"。

**30 天窗口 3 条建议**：
1. **立刻停掉"通用大脑/超级大脑"叙事**，对外只讲一句：*"把专家经验变成带审计、可复核、会标'我没验证过'的操作手册。"*（"大脑"是融资自嗨词，是销售死刑）
2. **All-in 知识蒸馏一个垂直切片**，30 天内拿到 **1 个付费试点**。选窄场景（安全生产 SOP / NGO 田间手册 / 制造作业指导书），做一个**真能用的网页 UI**（不是命令行 demo），带潜在客户的真实领域知识现场跑。免费 MCP 分发全停，改"试用→按席位/按手册收费"。
3. **机器人/财务/虚拟村庄 demo 全部移出对外材料**——它们现在是负债：财务 demo 的自夸式因果会砸招牌，机器人 demo 的"真实部署"措辞会被戳穿。内核留着当后台，前台只露知识蒸馏。

## 七、一句话结论

**内核的数学与证明机制是认真的（这是资产），但演示层在替它撒谎（这是负债），产品叙事悬浮在愿景层（这是销售死刑）——先花一天把 10 个 P0 修到"声明=代码"，再让知识蒸馏带着真客户跑起来，其余 demo 收进后台。**
