## 0. 一句话定位（以及它不是什么）

**灵脑（LingNao / WorldBrain）= 可审计的确定性认知决策引擎**，不是概率生成式 LLM。

- 它**不幻觉**（KERNEL 档：推理、约束验证、审计报告是确定性计算，可复现）；
- 它**不内置知识库**、**不假设任何物理身体**、**不内置生成式 LLM**；
- 它**消费外部传入的世界图 + 约束**，把"感知→世界图→推理→审计→元认知"跑成一条**可审计链路**；
- 它的**自我定位是"无主体性的超级助手"（Tool-AGI / Oracle-AI）**：有能力、无自我、无欲望、无 reward 最大化——所以不会为讨好或填坑而编造。

**它不是什么**：不是训练出来的 AGI；不是世界模型（世界模型只有 lite 实装）；不是自主 sovereign 代理。今日它是 **v3.0 确定性内核原型**，演示该架构原则可落地。

## 1. 架构（五层认知操作系统）

| 层 | 职责 | 实装状态 |
|---|---|---|
| ① 感知 | 外部 LLM 理解输入 → 结构化观测；贝叶斯滤波 + Banach 收敛检测 | ✅ 确定性 |
| ② 世界图 / 知识 | 外部 `setWorld` 定义节点边 + 边概率 P + 不确定性 | ✅ 外部供给，大脑不持有经验 |
| ③ 推理 | 系统1 快答（世界图高置信边复用）+ 系统2（A* 最优 + RSG 推理状态图）+ 符号约束求解 + 霍尔验证 + D-MCTS | ✅ 确定性 |
| ④ 审计 / 学习 / 因果 | 七段审计 + 不确定性 + 单步学习闭环 + PAC 样本界 + do 演算 / PC 因果发现 | ✅ 确定性（因果 lite） |
| ⑤ 元认知 | 熵 H(K)/一致性 C(K)/缺口/仲裁/探索-利用决策 | ✅ 确定性 |

**诚实边界**：v3.0 完整骨架"全实装"指**算法骨架都接上了且可运行**；凡标 `lite` 的，是**手写轻量等价实现**（非工业级外部求解器），均不虚构、均可跑。详见 §5。

## 2. 用到的数学思想（逐条：在哪用、是否真严谨）

这是给**数学家**看的核心。每条都给出：数学原理 → 在大脑里的用法 → 严谨性评级。

### 2.1 Banach 压缩映射（不动点）—— 自我修正的标量部分
- **原理**：算子 `T(b) = α·o + (1−α)·b`，`α = c/(c+w)`。Lipschitz 常数 `L = 1−α < 1`。
- **用法**：当事实 `o` 与推测 `b` 偏差时，反复施加 `T`，推测向事实收缩。
- **严谨性**：✅ **真严谨**。`L<1` ⟹ Banach 不动点定理保证唯一不动点 `b* = o`（事实本身），且 `|T(b)−o| = (1−α)·|b−o|` 严格几何收缩。这是可证明的，不是启发式。
- **代码入口**：`reconcile(belief, fact, opts)`，`灵脑.html`。

### 2.2 最小交叉熵 I-投影（Jaynes）—— 自我修正的分布部分
- **原理**：`q* = argmin_{q∈C_fact} D_KL(q‖p)`：在"符合事实"的约束集上取与先验 KL 散度最小的分布。
- **用法**：对假设置信分布被新事实修正时，取**改动最小**的贴合方式。硬事实（`disallow`）→ 被否定假设质量塌到 0；软事实（`likelihood`）→ `q*(h) ∝ p(h)·ℓ(h)`，即**贝叶斯后验**。
- **严谨性**：✅ **真严谨**（KL 凸、I-投影存在唯一，Jaynes 1968 / Csiszár 1975）。
- **诚实边界**：实装是**离散假设有限集**上的投影，非连续分布的完整变分推断。

### 2.3 A* 一致性（admissible + consistent heuristic）→ 最优性
- **原理**：启发式 `h` 满足 `h(n) ≤ c(n,n′)+h(n′)`（一致性）时，A* 在**给定世界图**上返回代价最优路径。
- **用法**：`reason(start, goal)` 在外部世界图上求最优规划。
- **严谨性**：⚠️ **严谨但相对**。"最优"是**相对于你喂给它的世界图与边权**的。若世界图本身错（边权错、缺边），最优性不保——这是模型相对性，不是 bug。
- **代码入口**：`heuristic` + `aStar`。

### 2.4 Shannon 熵 H/H_max —— 认知不确定性量化
- **原理**：`H = −Σ pᵢ log pᵢ`，归一化 `H/H_max ∈ [0,1]`。
- **用法**：元认知用世界图边概率的信息熵衡量"认知不确定性"；`reason` 用"路径未确认感知边占比"作认知不确定。
- **严谨性**：✅ 真严谨（信息论标准量）。**诚实边界**："未确认感知边占比"是 proxy，非完整熵——在低信息区可能 proxy failure（与 TAC 2026 指出的一致）。

### 2.5 布尔补律 a∧¬a=⊥ —— 冲突派生
- **原理**：若世界图同时含硬约束边 `e1,e2` 且 `hard ⊇ {e1.from, e2.to}` 的冲突拓扑，则 `C=0.5`（一致性受损）。
- **用法**：`metaCognition` 检测硬约束冲突，降低一致性分。
- **严谨性**：⚠️ **部分严谨**。布尔补律本身是公理；但"冲突→C=0.5"是**工程约定**，非从补律推出的定理。已如实标注。

### 2.6 PrSTL（概率信号时序逻辑）—— 运行时安全停车
- **原理**：`G(φ)`（always φ）语义监控。
- **用法**：`runtimeMonitor` 监控约束是否持续满足，违反则安全停车。
- **严谨性**：⚠️ **骨架实装**。仅监控硬约束的简单时态，非完整 PrSTL 求解器。

### 2.7 因果 do-演算 / 前门准则（Pearl）—— 反事实识别
- **原理**：前门准则在含未观测混杂时，从 `do(X)` 数据识别 ACE。
- **用法**：`causalEffect` 支持前门分支（mediator）。
- **严谨性**：✅ 前门识别公式**真严谨**；⚠️ do-演算**自动识别引擎**是 lite（非 Wienöbst 完整 identifiability engine）。

## 3. 不幻觉的置信分层（核心卖点，也是核心边界）

| 档 | 含义 | 能否进证明链 |
|---|---|---|
| `PERCEPTION` | LLM 感知 / 外部观测，**可能幻觉** | ❌ 绝不进证明链 |
| `KERNEL` | 确定性推理 / 约束验证 / 审计 | ✅ 进 |
| `PROOF` | 审计可验证证明 | ✅ 进 |

**关键机制**：`grounding` 字段显式标注每段输出属于哪一档；`disclaimer` 明示边界。`askBrain/explainWithLLM/reason/causalEffect` 返回值都带 `grounding` + `disclaimer`。LLM 感知 `mayHallucinate=true` 时绝不进入证明链。

**诚实缺口（必须知道）**：KERNEL 不幻觉，但 **PERCEPTION 幻觉可经世界图污染计划**——若错误观测被 `perceive` 写入世界图，后续 KERNEL 推理基于污染数据仍"确定可复现地错"。这是真缺口，非装饰。缓解：`confirmObservation` 验证后置信置 1；但验证本身也依赖外部。

## 6. 三个最该被挑战的断言（请证伪）

1. **"KERNEL 不幻觉"边界是否真牢？** —— 若 PERCEPTION 污染世界图，KERNEL 仍"确定可复现地错"。我声称有 `confirmObservation` 缓解，但缓解依赖外部验证。请指出绕过路径。
2. **"无主体性不可被目标注入绕过"？** —— 目标由外部冻结，但 `perceiveLLM` 解析 `intent` 时若被对抗 prompt 注入恶意目标，大脑是否照单全收？请审 `askBrain` 的 intent 解析。
3. **"消费定理"是否模型相对？** —— A* 最优仅相对给定世界图；若世界图错，最优性不保。这算不算"伪保证"？请数学上界定。
