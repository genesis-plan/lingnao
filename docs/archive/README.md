## 为什么归档而不是删除

这些文档记录了**决策的来路**。比如「为什么选择 A* 而不是采样规划」、
「为什么 LLM 只做感知不做推理」这类问题的答案，往往只在过程稿里。

但放在顶层会让新来的人分不清主次 —— 25 个 md 平铺时，
`README.md` 和 `灵脑_小说脑洞消费对照.md` 是并列的，这不合理。

所以：顶层留给使用者，过程稿收在这里，并明确标注"不代表当前状态"。
